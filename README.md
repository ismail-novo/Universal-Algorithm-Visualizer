# Universal Algorithm Visualizer

## Project Overview

Universal Algorithm Visualizer is an interactive desktop application developed using **Python** and **Tkinter** to help students understand algorithms and data structures through step-by-step visualizations. The application provides an intuitive graphical interface that makes learning complex concepts easier and more engaging.

This repository contains both the **Previous Version** and the **Latest Updated Version** of the project.
