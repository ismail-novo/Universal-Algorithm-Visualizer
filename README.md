# Universal Algorithm Visualizer

## Project Overview
Universal Algorithm Visualizer is an interactive application designed to help students and developers understand algorithm concepts through visual representation. It provides an easier way to learn and analyze different algorithms step by step.

## Features
- Interactive visualization of algorithms
- Step-by-step execution
- Easy understanding of algorithm behavior
- User-friendly interface
- Supports different algorithm categories

## Technologies Used
- Python
- Tkinter
- Jason
## How to Run
1. Download or clone the repository.
2. Run the main Python file.
